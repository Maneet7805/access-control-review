```sql
-- Restrict public.admin_delete_user to server-side (service_role / owner) use only.
-- Loops over every overload so it works whatever the argument list is,
-- and does nothing if the function doesn't exist.
DO $$
DECLARE
  fn regprocedure;
BEGIN
  FOR fn IN
    SELECT p.oid::regprocedure
    FROM pg_proc p
    JOIN pg_namespace n ON n.oid = p.pronamespace
    WHERE n.nspname = 'public'
      AND p.proname = 'admin_delete_user'
  LOOP
    EXECUTE format('REVOKE EXECUTE ON FUNCTION %s FROM PUBLIC, anon, authenticated', fn);
  END LOOP;
END
$$;
```

After this, `anon` and `authenticated` clients can no longer call `admin_delete_user` through the API. Call it only from your server using the `service_role` key, which keeps its access.
